# THE MILKSHAKE INCIDENT

A browser-based 3D comedy/action game. You sit down for a normal fast-food meal. Then you are in a car. Then there are UFOs. Then the horses need buckets of chicken.

Nothing explains itself. That is the point.

## Play

```bash
npm install
npm run dev
```

Open the local URL Vite prints (usually `http://localhost:5173`).

```bash
npm run build
npm run preview
```

Skip the diner intro while testing:

`http://localhost:5173/?drive=1`

## Controls

- **Mouse** — look around
- **Click** — eat (diner) / shoot (car)
- **WASD** — drive
- **Space** — shoot
- Drive close to a hungry horse while holding a Yardbird pail to feed it

## Objective

Destroy 10 UFOs. After that the game never ends. Keep driving.

## Stack

Vite + Three.js. No pre-made game assets, no copyrighted branding. Food buckets are fictional **YARDBIRD** pails.
